Data quality corrections applied to the source CSV: (1) the original points column was found to be an exact duplicate of goal_difference in all 354 rows — a source export error — so points shown here are recomputed with standard 3/1/0 scoring. (2) For 113 historically prominent clubs (Real Madrid, Bayern Munich, Barcelona, Man Utd, Juventus and peers), spreadsheet software had auto-converted the goals field into a time value (e.g. “1076:55:00”), corrupting Goals Against. Goals For survived intact, so Goals Against was recalculated as Goals For − Goal Difference (goal_difference itself checks out against the 241 unaffected rows). Full methodology and the underlying measure catalog ship in the companion Excel workbook.
